Conecta YouTube GRATIS

La app usa la YouTube Data API v3. Google la ofrece sin costo (10.000 unidades/día ≈ 100 búsquedas). Solo necesitas tu clave gratuita:

  1. Entra en console.cloud.google.com con tu cuenta de Google y crea un proyecto (o usa uno existente).
  2. Menú ☰ → API y servicios → Biblioteca → busca "YouTube Data API v3" y pulsa HABILITAR.
  3. Ve a Credenciales → Crear credenciales → Clave de API. Copia la clave generada.
  4. Pégala aquí abajo y guarda. Se memoriza en tu navegador.

⚠ Cada búsqueda consume ~100 unidades + 1 por lote de datos (el filtro de fecha, TENDENCIAS y la FICHA no cuestan extra).
🔒 Tu clave solo se guarda en tu navegador (localStorage) y se envía directamente a Google.
💡 La IA y el reproductor funcionan sin clave, son 100% libres.
