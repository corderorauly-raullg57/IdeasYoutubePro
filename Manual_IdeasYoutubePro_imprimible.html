1 · Qué hace la app

Convierte una idea escrita en una lista completa de videos de YouTube: los busca, los agrupa por autor o por ranking, mide su grado de aceptación (0–100), los reproduce con controles completos, muestra el perfil y contacto del creador, permite descargarlos verificando su licencia y exporta todo a CSV o guion.

Servicios gratuitos que usa: YouTube Data API v3 (cuota gratis de Google) · Pollinations.ai (IA sin registro) · YouTube IFrame Player API · yt-dlp (open source, solo para descargas).

2 · Puesta en marcha (una sola vez)

#Paso
1Guardar IdeasYoutubePro.html y Abrir_IdeasYoutubePro.bat en la misma carpeta.
2Doble clic en el .bat → la app se abre en http://localhost:8080 (imprescindible en Firefox).
3Pulsar ⚙ ¿Cómo conecto YouTube? y seguir el asistente: crear proyecto en console.cloud.google.com → habilitar YouTube Data API v3 → crear Clave de API → pegarla y guardar.
4El indicador de la cabecera pasa a ● API CONECTADA. La clave queda memorizada en el navegador.

6 · Perfil y contacto del autor

Botones: 👤 (monitor) · 👤 AUTOR (ficha del video y teatro). Muestra banner, avatar, nombre, país, antigüedad, suscriptores · vistas totales · nº de videos, descripción completa y contactos detectados en el perfil público:

✉️ Correos🟢 WhatsApp📸 Instagram🎵 TikTok🐦 X📘 Facebook🎮 Twitch✈️ Telegram🌐 Web

🔒 La API de YouTube no expone datos privados. Si el creador no publicó contactos, la app lo indica. El correo comercial oficial solo aparece en la pestaña «Acerca de» del canal (botón ℹ incluido).

7 · Descargar videos y licencias

Botón ⬇ DESCARGAR con un video en reproducción. Primero verifica la licencia vía API:

SemáforoSignificado
✅ CC-BYEl autor permite descargar y reutilizar citando la fuente.
🔐 EstándarDerechos reservados. Descarga solo para uso personal; para reutilizar, pedir permiso (👤 AUTOR).
ℹ No disponibleNo se pudo verificar: asumir derechos reservados.

Después se elige formato (🎬 MP4 1080/720/360/mejor · 🎧 MP3) y se obtiene: 💾 Script .bat (doble clic → instala yt-dlp/ffmpeg si faltan y descarga en Descargas\IdeasYoutubePro) o ⧉ Comando copiado para CMD. Si el autor bloqueó el contenido (edad, miembros, región), el script lo reporta como restricción de derechos.

9 · Solución rápida de problemas

ProblemaSolución
No se reproduce (Firefox)Abrir con el .bat (localhost), no con doble clic. O 🛡 → desactivar protección en este sitio.
Cuota agotadaSe reinicia cada 24 h (10.000 unidades gratis).
Clave no válidaRevisarla en ⚙ — debe empezar por AIza….
Sin resultadosReformular la idea o usar ✦ Ampliar con IA.
Falla una descargaLeer el mensaje del .bat: suele ser restricción de derechos o falta ffmpeg.
